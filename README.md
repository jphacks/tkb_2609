## モックの起動（Issue #3）

Node.js 22.12 以上を使用します。

```sh
npm ci
npm run dev
```

表示された URL を開き「管理者として体験」または「メンバーとして体験」を選択します。ログアウトすると別の役割でも確認できます。新規登録後、参加コード `ABCD2345` でデモチームへの参加、または新しいチームの作成を試せます。コードを再発行した場合は設定画面の新しいコードを使用してください。

- Firebase への接続、実メール送信はありません。登録には架空の情報を使ってください。
- 登録アカウント・変更したデータはメモリ上のみ保持され、再読み込みで初期化されます。デモの役割のみ同じブラウザで復元します。
- 予定の日付は起動日から生成します。出欠の未回答は出席として表示します。
- データ操作は `src/repository.ts` の `Repository` に集約しています。Firestore 版ではこの実装を差し替えます。モックの認可チェックは本番のセキュリティルールを代替しません。

```sh
npm test
npm run build
```
