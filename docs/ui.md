# 画面構成とデザイン原則

## デザイン原則

- シンプルで清潔感のあるデザイン。白基調、余白を多めに、色は意味のある所（予定の種類、用具の状態）にだけ使う
- スマホの縦画面が基準。ほかの画面サイズ・向きでは下の「画面サイズと向き」に合わせて表示を変える
- 押せる部分は指で押しやすい大きさ（目安 44px 以上）
- iPhone の画面下部（ホームインジケーター）やノッチに要素が重ならないようにする（`env(safe-area-inset-*)`）
- LINE 内ブラウザでも崩れないこと（上下にツールバーが出る前提で、`100vh` ではなく `100dvh` を使う）
- UI の呼び方は「チーム」「メンバー」。スポーツ名を出さない

## 画面サイズと向き

CSS のメディアクエリで、開いた端末の画面の大きさと向きを判定してレイアウトを切り替える。スマホ縦での操作方法は変えない。

| 条件 | ナビゲーション | 用具の一覧 | 詳細・編集 | シート（メニュー） |
| --- | --- | --- | --- | --- |
| スマホ縦（基準） | 下部タブバー | 1 列 | 全画面 | 下からせり上がる |
| 幅 700px 以上（タブレット縦など） | 下部タブバー | 幅に応じて 2 列以上 | 中央のパネル（幅 680px） | 中央のダイアログ |
| 幅 900px 以上（PC・タブレット横） | 左側のレール | 幅に応じて 2 列以上 | 中央のパネル | 中央のダイアログ |
| スマホ横（高さ 500px 以下） | 左側のレール（縦の高さを確保） | 2 列 | 中央のパネル | 中央のダイアログ |

- **予定の一覧は、どの画面でも 1 列**。広い画面では幅 720px までにして中央に置く
- 用具の一覧の列数は `grid-template-columns: repeat(auto-fill, minmax(...))` で幅から自動で決める
- 予定の作成画面の「日付」「集合時間」は、2 つ並べると窮屈な狭い画面（幅 360px 未満など）では縦に並べる。iOS Safari の日付・時刻欄は標準表示だと崩れるため、ほかの入力欄と同じ見た目に揃える
- 横向きのスマホでは、ノッチ側に要素が重ならないよう左右の safe area も考慮する

## 全体レイアウト

```
┌─────────────────────────┐
│ チーム名          [↻]    │ ← ヘッダー。↻ = データ再取得
├─────────────────────────┤
│                         │
│      各タブの内容        │
│                         │
├─────────────────────────┤
│  予定  │  用具  │  設定  │ ← 下部タブバー
└─────────────────────────┘
```

## 画面一覧

| 画面 | 内容 |
| --- | --- |
| 紹介ページ | 未ログイン時の入口。機能紹介・使い方・よくある質問、新規登録とログインへの導線。共有されたアプリのリンク（`?openExternalBrowser=1`）から開いたときは出さず、ログイン画面から始める（#79） |
| ログイン | メール、パスワード。新規登録・パスワード再設定・紹介ページへの導線 |
| 新規登録 | 表示名、メール、パスワード（条件を入力中に表示）。ログイン・紹介ページへの導線 |
| チーム参加／作成 | 参加コード入力、または「チームを作る」 |
| 予定一覧 | カードのリスト、右下に追加ボタン（権限があるときのみ） |
| 予定詳細 | 全項目、出欠状況、メモ |
| 予定の作成・編集 | 種類、予定名、日付、集合時間、場所。追加時は「1回だけ／毎週」を切り替えられ、毎週では曜日・開始日・終了日と追加される日付の一覧を表示 |
| 用具 | 自分の状態ウィジェット ＋ 用具一覧、追加ボタン |
| 設定 | 自分の表示名、チーム情報、（管理者）参加コード・権限・種類の設定、ログアウト |

## 予定カード

```
┌─────────────────────────────┐
│▌10/25(土)  [練習]            │ ← 左端の色帯と種類バッジで種類を示す
│▌午前練習                     │
│▌集合 8:30 ・ 第2グラウンド    │
│▌[出席][欠席][見学][遅刻][早退] │ ← 自分の出欠。選択中のボタンを強調
└─────────────────────────────┘
```

- 5 つのボタンは 1 行に収める
- 場所が長いときは省略記号（…）で切る

## 用具タブ

```
┌─────────────────────────────┐
│ あなたが持っている用具         │ ← ウィジェット（用具の枠より大きく）
│  ビブス           [手放す]    │
│  ボール袋         [手放す]    │
└─────────────────────────────┘
┌─────────────────────────────┐
│ コーン                [持つ]  │ ← 誰も持っていない（上にまとまる）
└─────────────────────────────┘
┌─────────────────────────────┐
│ 救急箱             [山田]    │ ← 誰かが持っている（下にまとまる、枠の色が違う）
└─────────────────────────────┘     持っている人の名前は右側だけに表示
```

- 各用具の右端に「…」メニュー（名前の編集・削除）。管理者には、他人が持っている用具のメニューに「手放させる」を出す
- 並び替えが起きたときは短いアニメーションで動きを見せると、何が起きたか分かりやすい

## アプリアイコン（#29）

青背景に丸みのある白い「ぶ」を置いたアイコンを使用する。原本は `public/icons/bukatsu-bu-1024.png`（1024×1024px）。ログイン画面・読み込み画面は192px版、タブのfaviconは32px版、iOSのホーム画面用は180px版を参照する。Web App Manifestには192px・512px版を登録する。

ログイン画面と読み込み画面では共通の `AppLogo` で表示し、旧ロゴと同じ比率（64pxに対して半径14px、21.875%）で角を丸める。ホーム画面用の画像原本はOS側のマスクを前提に正方形を維持する。

各サイズは同じ原本の縮小版。新しいデザインに変更するときも、参照と全サイズを揃えて更新する。既存のホーム画面アイコンは端末側に保存されているため、更新後も古い「B」が残る場合はホーム画面から削除して追加し直す。
