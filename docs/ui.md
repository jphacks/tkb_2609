# 画面構成とデザイン原則

## デザイン原則

- シンプルで清潔感のあるデザイン。白基調、余白を多めに、色は意味のある所（予定の種類、用具の状態）にだけ使う
- スマホの縦画面が基準。PC では中央にスマホ幅で表示すれば十分
- 押せる部分は指で押しやすい大きさ（目安 44px 以上）
- iPhone の画面下部（ホームインジケーター）やノッチに要素が重ならないようにする（`env(safe-area-inset-*)`）
- LINE 内ブラウザでも崩れないこと（上下にツールバーが出る前提で、`100vh` ではなく `100dvh` を使う）
- UI の呼び方は「チーム」「メンバー」。スポーツ名を出さない

## 全体レイアウト

```
┌─────────────────────────┐
│ チーム名          [↻]    │ ← ヘッダー。↻ = データ再取得
├─────────────────────────┤
│                         │
│      各タブの内容        │
│                         │
├─────────────────────────┤
│  予定  │  用具  │  設定  │ ← 下部タブバー
└─────────────────────────┘
```

## 画面一覧

| 画面 | 内容 |
| --- | --- |
| ログイン | メール、パスワード。新規登録とパスワード再設定への導線 |
| 新規登録 | 表示名、メール、パスワード（条件を入力中に表示） |
| チーム参加／作成 | 参加コード入力、または「チームを作る」 |
| 予定一覧 | カードのリスト、右下に追加ボタン（権限があるときのみ） |
| 予定詳細 | 全項目、出欠状況、メモ |
| 予定の作成・編集 | 種類、予定名、日付、集合時間、場所 |
| 用具 | 自分の状態ウィジェット ＋ 用具一覧、追加ボタン |
| 設定 | 自分の表示名、チーム情報、（管理者）参加コード・権限・種類の設定、ログアウト |

## 予定カード

```
┌─────────────────────────────┐
│▌10/25(土)  [練習]            │ ← 左端の色帯と種類バッジで種類を示す
│▌午前練習                     │
│▌集合 8:30 ・ 第2グラウンド    │
│▌[出席][欠席][見学][遅刻][早退] │ ← 自分の出欠。選択中のボタンを強調
└─────────────────────────────┘
```

- 5 つのボタンは 1 行に収める
- 場所が長いときは省略記号（…）で切る

## 用具タブ

```
┌─────────────────────────────┐
│ あなたが持っている用具         │ ← ウィジェット（用具の枠より大きく）
│  ビブス           [手放す]    │
│  ボール袋         [手放す]    │
└─────────────────────────────┘
┌─────────────────────────────┐
│ コーン                [持つ]  │ ← 誰も持っていない（上にまとまる）
└─────────────────────────────┘
┌─────────────────────────────┐
│ 救急箱               山田    │ ← 誰かが持っている（下にまとまる、枠の色が違う）
│ 山田                         │
└─────────────────────────────┘
```

- 管理者には、誰かが持っている用具の枠に「手放させる」操作を出す（長押しやメニューなど、通常の操作と見分けがつく形にする）
- 並び替えが起きたときは短いアニメーションで動きを見せると、何が起きたか分かりやすい
