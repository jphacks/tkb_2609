- [x] 詳細から用具／設定へ直接移動でき、詳細が重ならない。詳細で予定を押すと一覧へ戻る。

## チーム削除（#104）

削除してよい専用テストチームだけで確認する。通常利用中のチームは使わない。

- [x] 削除確認に最低件数と、メモ等を含まないこと、1000件ごとの停止・再開の説明が出る。キャンセルでデータが消えない。
- [x] 削除中は今回完了を確認できた操作数と段階を表示する。処理が十分長い場合は「処理の区切りで停止」で停止し、「削除を再開」で完了できる。
- [x] 停止中に別チームを利用できる。元のチームへ戻って再開でき、完了後も他チームの所属・データが残る。

小さなチームでは処理が速く、停止ボタンを押す前に完了することがある。停止・1000件上限・quotaエラー・101/500件の出欠境界はエミュレータの自動テスト済み。本番で大量ユーザーを登録したり、無料枠を使い切ったりして再現する必要はない。
